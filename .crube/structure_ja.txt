src/	拡張のソース（TypeScript）
	extension.ts	エントリポイント：コマンド mtqg.open と、パネルを復元するシリアライザを登録する
	mtqg/	mtqg の CLI を子プロセスで呼び、--json の出力に型を付ける
		availability.ts	mtqg が PATH にあり、版が足りているか（MIN_SUPPORTED_MTQG_VERSION）を確かめる
		client.ts	拡張が使う mtqg のコマンドごとの、型つきの関数
		errors.ts	mtqg が標準エラーに出す --json の行から読んだエラーと警告
		index.ts	src/mtqg/ が外に出すもの
		process.ts	mtqg を execFile と --json で動かし、出力を読む
		types.ts	拡張が読む、mtqg の --json の出力の型
	webview/	mtqg パネル：6つのタブを持つ Webview
		client/	Webview の中で動くスクリプト（DOM の型、ブラウザ向け ES モジュール、別の tsconfig）
			main.ts	ホストから届いた HTML を差し込み、クリックと入力をホストへ送る
			tsconfig.json	Webview のスクリプトのコンパイラ設定
		controller.ts	Webview のメッセージ→mtqg の呼び出し→描画。表示の状態を持つ（vscode 非依存）
		panel.ts	WebviewPanel を開く・前に出す・復元する。ここで vscode を触る唯一のファイル
		screens.ts	renderScreen がタブごとの描画へ振り分ける。renderError もここ
		screens/	画面ごとの HTML をホスト側で組む（vscode 非依存）
			bugs.ts	Bug 画面：bug・reply の文言で renderThread を呼ぶ
			composer.ts	Memo の入力欄のスラッシュコマンド（/todo・/t など）を解釈する
			format.ts	日付を利用者のタイムゾーンで表示用に整える
			glossary.ts	Glossary 画面：表。同じ語が複数回定義されていたら目立たせる
			memos.ts	Memo 画面：log --events から、全種類の記録のタイムラインを描く
			questions.ts	QA 画面：question・answer の文言で renderThread を呼ぶ
			rules.ts	Rule 画面：ただの表
			table.ts	画面に共通の部品：編集できる文字、削除と ID のボタン、バッジ
			thread.ts	QA と Bug に共通のスレッドの画面：返信つきの行と、返信欄
			todos.ts	Todo 画面：Keep 風のカード。完了したものは開いているものの上に
		shared/	6画面に共通（vscode 非依存）
			escape.ts	HTML に差し込む前のエスケープ
			html.ts	renderShell：CSP・タブバー・各画面を包むタブパネル
			messages.ts	ホストと Webview の間のメッセージの型と検証
			tabs.ts	6つのタブの ID・ラベル・既定のタブ
